## Dependencies

- [libX11](https://www.x.org/releases/current/doc/libX11/libX11/libX11.html)

## Build

```console
$ cc -o nob nob.c
$ ./nob
```

## Usage

```console
$ ./main
```

## Development

For Nix users, there is a `shell.nix` available which declares the main dev dependencies of the program.

```console
$ nix-shell
```
